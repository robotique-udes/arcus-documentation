# Introduction
Welcome to ARCUS! In these tutorials, you will learn how to navigate through the different ARCUS repos, use our custom tools and even develop your own code.

## Environnment setup

Before starting, make sure that you have the correct environnment setup. The detailed procedure for installation and configuration is available in the [**setup section**](../code-and-simulation/setup_up.md). Feel free to ask any of our members for help if needed!

## Recommended tutorials

Here is a list of relevant tutorials and courses to help you get better with our technologies. They are recommended, but not stricly mandatory if you prefer to get directly into the ARCUS project.
* [ROS2 Humble tutorials](https://docs.ros.org/en/humble/Tutorials.html). ARCUS uses the ROS2 Humble distribution. This tutorial helps understanding how ROS works and how to use it.
* [Roboracer lectures](https://roboracer.ai/course). This course is available direclty on the [Roboracer website](https://roboracer.ai/) and contains the most recent version of the lectures given in the Roboracer class at UPenn.
* [Roboracer/F1Tenth course](https://f1tenth-coursekit.readthedocs.io/en/latest/index.html). The Roboracer organization offers a free course made specificaly for autonomous 1/10th vehicle projects. In this course, you will learn to code, use ROS2 and develop autonomous driving logic in a more concrete way. The course is divided in two main sections : **Modules** that contain lectures and general theory on each topic and **labs** that allow you to put the theory in practice. Each module has its corresponding lab. The labs even have a quick explanation on how to approach the solution.
