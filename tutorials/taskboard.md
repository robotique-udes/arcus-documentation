# The ARCUS taskboard

[View the ARCUS taskboard](https://github.com/orgs/robotique-udes/projects/3)

We use the integrated Github "*Scrum*" board to organise our tasks, define our objectives.

## Task priority

Each task has a priority based on the criticality of the task (low to urgent). Some tasks are more urgent/relevant than others. We make sure to define the level of each task to prioritize our work.

## Task state

Each task is located in a column corresponding to its state. There are currently five states :

* **Todo** : A task that hasn't been started yet.
* **In progress** : A task that has been started but not completed yet.
* **In review** : Each new block of code in the project has to be verified and approved by another member. This ensures cleaner code, fewer mistakes and is in general a widespread good practice. Read the [Git/Github usage](git.md) section to understand this further.
* **To be tested** : A task has been completed and reviewed, but remains to be tested.
* **Done** : Completed tasks.

## Task assignee

Each task can be assigned to one or more members of the project. They will be in charged of completing the task.

## Github integration

With Github, you can link each task (issue) to a branch or a commit that solves it. It is made using the `development` section in the task's panel.
